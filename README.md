# 어디나라? — 세계지도 위치 게임

나라 이름을 보고 세계지도에서 해당 위치를 찾는 한국어 지리 학습 게임입니다.

## 주요 기능

- 전 세계 국가 무작위 10문제 도전
- 아시아·유럽·아프리카·북미·남미·오세아니아 대륙별 학습
- 틀린 국가를 자동으로 모아 다시 출제하는 오답 복습
- 첫 시도 정답, 연속 정답, 점수 및 학습 기록 저장
- 작은 국가를 위한 지도 확대와 단계별 힌트
- 모바일, 태블릿, PC 반응형 화면

## 실행 방법

```bash
npm install
npm run dev
```

브라우저에서 `http://localhost:3000`을 열면 됩니다.

## 배포

Next.js로 제작되어 Vercel에서 바로 배포할 수 있습니다.
